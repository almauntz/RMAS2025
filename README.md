# Razvoj mobilnih aplikacija i servisa – 2025

Dobrodošli u zvanični repozitorij predmeta **Razvoj mobilnih aplikacija i servisa (RMAS)**  
na Fakultetu elektrotehnike Univerziteta u Tuzli.

Ovaj repozitorij sadrži **primjere sa predavanja** i **materijale za vježbe**  
koji prate sadržaj predmeta tokom akademske 2025/2026. godine.
